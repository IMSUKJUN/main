# GodDaeHee Hub Page View

Claude 웹(claude.ai)의 대화를 무한 스크롤 대신 **페이지 단위**로 나눠서 보는 크롬 확장입니다.
현재 페이지에 속한 메시지만 남기고 나머지는 화면에서 빼기 때문에, 긴 대화에서도 위아래로
계속 굴리지 않고 페이지를 넘겨 가며 읽을 수 있습니다.

이 저장소의 다른 파일과는 별개로 동작하는 독립 프로그램입니다.

## 설치 (개발자 모드)

1. 크롬 주소창에 `chrome://extensions` 를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드** 를 누르고 이 저장소의 `extension` 폴더를 고릅니다.
4. `https://claude.ai` 를 열면 화면 오른쪽 아래에 페이지 도구 막대가 나타납니다.

크롬 111 이상이 필요합니다(`color-mix()` 사용).

## 쓰는 법

| 조작 | 하는 일 |
| --- | --- |
| `‹` `›` | 이전 / 다음 페이지 |
| `⏮` `⏭` | 첫 페이지 / 마지막 페이지 |
| 페이지 입력칸 | 숫자를 넣고 Enter를 누르면 그 페이지로 이동 |
| 묶음 크기 | 한 페이지에 넣을 메시지 수 (2·4·6·10·20) |
| ☰ 전체 보기 | 페이지 나누기를 잠시 끄고 대화 전체를 표시 |
| ⌃ 접기 | 도구 막대를 페이지 표시만 남기고 접기 |
| ✕ | 페이지 보기 끄기 (설정에도 저장됨) |

키보드

| 단축키 | 하는 일 |
| --- | --- |
| `Alt` + `Shift` + `←` | 이전 페이지 |
| `Alt` + `Shift` + `→` | 다음 페이지 |
| `Alt` + `Shift` + `Home` | 첫 페이지 |
| `Alt` + `Shift` + `End` | 마지막 페이지 |
| `Esc` (도구 막대 안에서) | 도구 막대 접기 |

입력창에 글을 쓰는 중이거나 한글 입력이 조합 중일 때는 단축키가 동작하지 않습니다.

설정은 확장 아이콘을 누르면 열리는 설정 페이지에서 바꿉니다. 바꾼 값은 바로 저장되고
열려 있는 Claude 탭에 즉시 반영됩니다.

## 알아 둘 점

- 페이지에 없는 메시지는 화면에서 빠지므로 브라우저 찾기(`Ctrl`+`F`)에 잡히지 않습니다.
  전체 보기를 켜면 다시 잡힙니다.
- 인쇄할 때는 페이지 나누기와 상관없이 대화 전체가 나옵니다.
- Claude 웹의 화면 구조(클래스 이름, `data-*` 속성)는 예고 없이 바뀔 수 있습니다. 확장은
  여러 후보 선택자를 두고 그때그때 다시 찾지만, 전부 실패하면 도구 막대가 오류 상태로 바뀌고
  **다시 찾기** 단추가 나옵니다. 설정 페이지의 *메시지 선택자 직접 지정* 에 선택자를 넣어
  수동으로 맞출 수도 있습니다.
- 이 확장은 대화 내용을 읽거나 어디로도 보내지 않습니다. 저장하는 값은 설정 일곱 개뿐이고
  `chrome.storage.sync` 에만 들어갑니다. 네트워크 권한도 요청하지 않습니다.

## 폴더 구조

```
extension/
  manifest.json              MV3 매니페스트
  icons/                     아이콘 (16/32/48/128)
  src/background/            설치 시 기본값 설정, 아이콘 클릭 처리
  src/content/
    tokens.css               디자인 토큰 (원시 토큰 + 의미 토큰)
    page.css                 문서에 넣는 유일한 규칙 (숨김·앵커·캡션·인쇄)
    toolbar.css              도구 막대 컴포넌트 스타일 (섀도 DOM 전용)
    constants.js             기본값, 선택자 후보, 문구
    store.js                 설정 읽기/쓰기/구독
    adapter.js               대화 영역과 메시지 찾기
    paginator.js             페이지 계산과 DOM 속성 쓰기
    toolbar.js               도구 막대 UI
    main.js                  전체 조립, 감시, 단축키, 테마
  src/options/               설정 페이지
docs/design-guidelines.md    디자인 시스템 규칙과 QA 체크리스트
test/                        크로미움에서 도는 통합 테스트
```

## 테스트

실제 claude.ai 대신, 같은 모양의 로컬 고정 페이지에 콘텐츠 스크립트를 그대로 넣고
크로미움에서 돌립니다.

```bash
npm test          # 또는: node test/pager.test.mjs
```

playwright 가 필요합니다. 전역 설치본을 쓸 때는:

```bash
NODE_PATH=$(npm root -g) node test/pager.test.mjs
```

`test/fixture.html` 은 브라우저로 직접 열어 손으로 확인할 때도 씁니다.

## 확인된 것과 확인되지 않은 것

- 확인됨: 페이지 나누기, 페이지 이동, 묶음 크기 변경, 답변이 계속 들어오는 상황, 메시지 삭제,
  대화 전환, 빈 대화, 전체 보기, 접기, 페이지 배경에 따른 밝은/어두운 전환, 끄기 후 원상복구.
  로컬 고정 페이지 기준 36개 검사 통과.
- 확인되지 않음: 실제 claude.ai 화면. 이 저장소에는 로그인된 claude.ai 에 접속할 수단이 없어
  `constants.js` 의 선택자 후보는 검증되지 않은 가정입니다. 실제 화면에서 한 번 확인한 뒤
  목록을 정리하는 작업이 남아 있습니다.
