Claude 웹 대화를 무한 스크롤 대신 페이지 단위로 나눠서 봅니다. 값을 바꾸면 바로 저장되고, 열려 있는 Claude 탭에 즉시 반영됩니다.

기본 동작

끄면 Claude 웹은 원래의 스크롤 화면으로 돌아갑니다.

질문과 답변을 각각 한 개로 셉니다. 6개면 대화 세 번 분량입니다.

입력창이나 사이드바를 가리면 다른 위치로 옮겨 주세요.

읽기 편의

마지막 페이지를 보고 있을 때만 따라갑니다.

예: 3 / 12 페이지 · 메시지 13–18

Alt+Shift+← 이전, Alt+Shift+→ 다음, Alt+Shift+Home 처음, Alt+Shift+End 마지막. 입력창에 글을 쓰는 중에는 동작하지 않습니다.

고급

Claude 웹 화면 구조가 바뀌어 페이지 나누기가 동작하지 않을 때만 사용합니다. 비워 두면 확장이 스스로 찾습니다.

!

알아 두면 좋은 점

  • 페이지에 없는 메시지는 화면에서 빠지므로 브라우저 찾기(Ctrl+F)에도 잡히지 않습니다. 도구 막대의 전체 보기를 켜면 다시 잡힙니다.
  • 인쇄할 때는 페이지 나누기와 상관없이 대화 전체가 나옵니다.
  • Claude 웹의 화면 구조가 바뀌면 페이지 나누기가 멈출 수 있습니다. 이때 도구 막대에 오류 상태와 다시 찾기 단추가 나타납니다.
